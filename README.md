# 🏷 guessing-game

The game gives the user as many trails to guess a number the computer has chosen. It gives indications such as hot or cold to tell the user if he is in the range of numbers. Then if a win the number of trails is displayed as well as a congratulations message.

---

## 📌 Problem Statement

I noticed in my class that less and less people areninterested in mathematical problems and are gradually loosing interest in math sums. The guessing-game will reanimate the excitement of finding a math problem right and this will also help them improve their logical reasoning

---

## 🎯 Project Goals

- Allow users to have unlimited number of trails to guess the number.
- Increase the exitement of more youths in complex mathematical logic.
- To have fun.
- And a pesonal goal for me is to deepen my bash skills.
